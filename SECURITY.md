## Reporting a Vulnerability

We take the security and integrity of the Repo Transfer Automation System seriously.
If you discover an architectural security vulnerability or credential handling defect:

1. **Do not disclose publicly via GitHub Issues.**
2. Send an encrypted or confidential report directly to:
   - **Lead Architect**: Shardendu Mishra
   - **Email**: mishrashardendu22@gmail.com
3. Please include:
   - Description of the vulnerability and attack vector.
   - Proof of concept or reproduction steps.
   - Recommended remediation.

You will receive an acknowledgment within 24 hours and a remediation advisory upon resolution.
